# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive. Criticise code and ideas, not people.
- No harassment, discrimination or personal attacks, in any project space.
- Assume good intent; ask before assuming.

## Scope

Applies to issues, pull requests, discussions and any other project space.

## Enforcement

Report unacceptable behaviour to the maintainers through a private report at
<https://github.com/four-bytes/four-git-mcp/security/advisories/new> (mark it as a conduct
report). Maintainers review every report and may remove content or restrict participation.
